Data self-test

This page checks every trace file in the browser. It does three things.

  1. Structure. It replays the recorded state changes and compares the result against every snapshot the file carries. It also makes sure that the step indexes run without a gap, and that the candidate table agrees with every recorded hash.
  2. Golden draws. It replays draws captured from the real abseil through the browser implementation of the index mapping.
  3. The engine. It runs the whole scenario again through the browser port of the reference and compares the result field by field. If anything differs, the sandbox and the lab say so instead of showing a wrong number.

tools/04_verify.py makes the same checks at build time, in Python, against the same files. This page checks what the browser actually downloads.
